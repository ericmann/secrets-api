# 0.2.1

Released 2026-09-25. A test-only release: nothing under `src/`, `plugin/`, or `cli/` changed, and the
API behaves exactly as in [0.2.0](0-2-0.md).

## Fixed

- **The tests failed on PHP 8.5.** PHP 8.5 deprecates `ReflectionMethod::setAccessible()` and
  `ReflectionProperty::setAccessible()`, which have done nothing since PHP 8.1. The test suite
  treats deprecations as errors, so the handful of tests that reach a private member through
  reflection errored. Those calls now run only when `PHP_VERSION_ID < 80100`, the same guard core's
  own tests use. The core patch on [#66187](https://core.trac.wordpress.org/ticket/66187) carries
  the same fix. Its PHP 8.5 CI jobs are what found this.

## Changed

- CI adds PHP 8.5 to the test matrix and to the WP-CLI smoke test, so the plugin's CI tops out
  where core's does. See the [CI reference](../reference/ci.md).
